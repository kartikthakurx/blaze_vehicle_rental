# 🚗 Blaze Vehicle Rental — Dynamic Fleet & Reservation Management System
Blaze Vehicle Rental is a full-stack web application designed to help customers browse vehicles, inspect detailed specifications, and book rides seamlessly with transparent hourly pricing and driver options, while providing an administrative dashboard to manage fleet inventory and reservations.

The project is built using PHP, MySQL, HTML, CSS, and JavaScript and includes separate customer and administrator functionality.

<br>

## ✨ Features

### 👤 Customer & User Features

- 🔐 **Authentication & Session State:** User signup, secure login, logout, and session-aware navigation header displaying the logged-in user greeting.

- 🚘 **Live Fleet Catalog:** Real-time showcase of rental vehicles with engine specs, fuel type, transmission, horsepower (BHP), and hourly rates (₹/hour).

- 🔍 **Interactive Vehicle Details Modal:** Multi-image gallery slider, detailed specs, interior/exterior overview, security deposit breakdown, and direct booking trigger.

- 📅 **Interactive Booking Engine:** Reservation scheduling with pickup/drop-off dates and times, vehicle quantity, pickup location, professional driver option, and driving license upload.

- 💳 **Checkout & Confirmation:** Seamless booking submission flow leading to confirmation (success.html) and direct tracking via reservation history (mybookings.php).

- 📁 **My Rides Dashboard:** Dedicated customer panel to monitor rental duration, vehicle count, driver status, total fare, live status badges (PENDING, COMPLETED, REJECTED, CANCELLED BY USER), and booking cancellation.

- 📩 **Direct Inquiries:** Customer contact form to submit queries with name, email, phone, subject, and message.

<br>

### 🛠️ Administrative & Operational Features

- 📊 **Executive Dashboard:** Real-time overview metrics for Total Users, Total Bookings, and Total Admins, plus a recent bookings table with quick detail links.

- ➕ **Fleet Registration Module:** Add new vehicles with complete specifications, hourly rates, descriptions, cover image, and up to 4 gallery slider images.

- ✏️ **Fleet Inventory Management:** Inspect and update existing vehicle specifications, pricing, descriptions, and cover imagery.

- 📋 **Reservation Logistics:** Searchable and filterable bookings table to review customer details, schedules, driver requests, uploaded license documents, and update booking statuses.

- 👥 **User Role Management:** View registered users and admins, inspect account roles and registration dates, and manage access.

- 📬 **Customer Message Desk:** View and manage inquiries submitted through the contact desk.

## 🎯 Project Objectives


### 🔄 Automate Manual Fleet Bookings
Replace manual booking records with a database-backed PHP & MySQL reservation system.

### ✨ Smooth Customer Experience
Provide clear vehicle specifications, image previews, driver options, and live booking status tracking.

### 🔐 Role-Based Operations
Separate customer workflows from protected admin controls over fleet, bookings, users, and inquiries.

### 🛡️ Reliable Session Handling
Maintain authenticated user and admin sessions across pages and booking flows.

### 💻 Practical Full-Stack Architecture
Demonstrate relational MySQL schema design, SQL queries, and server-side PHP processing.
